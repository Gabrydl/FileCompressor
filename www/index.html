    When it's done

    Program

    Off: size, formats and file-type options go back to the defaults every time the program opens.

    Format

    Privacy

    Removes where and with which phone the photo was taken. The picture itself doesn't change and stays the right way up.

    Size in pixels

    ×

    The photo fits inside this box and keeps its shape. Leave one side empty to set only the other. Smaller photos aren't enlarged.

    Video

    Speed

    Auto lowers resolution and frame rate only when the size you picked needs it. Best quality is slower.

    Trim

    On: open a video (or audio) in the list to set where it starts and ends. The size target counts only the part you keep.

    Audio

    Halves the size of voice recordings (lessons, voice notes, calls) with no audible loss. Leave it off for music.

    Without quality loss

    The pages look exactly the same. The file is also packed tighter every time. Digitally signed PDFs are always left untouched, and fonts in fillable forms are kept whole.

    Pictures

    Photos are made smaller only as much as needed to reach the size. Black and white shrinks scans a lot. Rebuilding pages as pictures is smallest for scans, but the text can't be selected anymore.

    Word, PowerPoint and Excel

    The file is always packed tighter. With this on, big pictures inside are also made smaller. Videos and sounds inside are left as they are. Files keep their format.
